# De Voorhoede GitHub organization files
Organization-wide configuration and templates that GitHub automatically applies across all repos in the org.

- The reusable [workflow templates](./workflow-templates/) are usable through GitHub's "Actions → New workflow" picker.
- The [pull request templates](./PULL_REQUEST_TEMPLATE/) are default PR templates.

Besides that this repo contains common cross-project Voorhoede files like:
- The [decision log](./common/decision-log/).
- A [GH actions dependabot config](./common/dependabot.yaml).
